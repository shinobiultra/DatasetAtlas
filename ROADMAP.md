# Remaining implementation roadmap

Closeout: 2026-09-22. The working application implements browsing, source filtering, saved selections, full-scope queries, detector/embedding analysis, maps, local model context, exchange, and controlled static publication. The frontend was then rebuilt against `ui-mockups/UI-Initial-Spec.md`: one application shell, a thumbnail-led catalogue, virtualized grid and table with scroll paging, focused inspection, A/B comparison, a full-workspace map, and deployment-aware coverage statements. SPEC.md remains the acceptance contract; this roadmap records remaining work, not completed claims.

1. **Expand real coverage.** Of 336 catalogue entries, 64 have verified local previews and 272 do not. There are 59 canonical full-scope indices, each limited to its pinned acquired population; partial media is explicit. Prioritize resolved accessible sources with no adapter, including Oxford Pets, DTD, and Waterbirds. IlluChar's 2.79 GB source is deferred work, not an access gate or a user-imposed download limit.
2. **Finish exact release reconciliation.** All 64 papers have full-text mention inventories and all 332 canonical corpus groups have research dispositions. This does not resolve every split, revision, source-family variant, or paper selection. Preserve uncertain identities and evidence rather than merging by name.
3. **Complete partial acquisitions.** GQA has a verified 100-image preview and all 132,062 validation-balanced question records indexed. Its 21,817,965,542-byte official image archive is now downloaded and SHA-256 verified (`reports/gqa-full-image-acquisition.json`). Browsing still uses the earlier partial-media snapshot: join referenced IDs, update the pinned source configuration, and rebuild the snapshot before upgrading coverage. SVO-Probes and JailBreakV media also retain explicit gaps. ViSU-Text, ZeroBench, and other actual gated sources need authorized access.
4. **Strengthen resource enforcement and edge cases.** DuckDB has a native memory setting and cancellable query timer; processor peak process RSS and CPU are not hard-capped. Extend null/mixed-type/cursor-drift query tests and remote-browser prefetch evidence. Video ranges operate over a bounded in-memory asset, not streaming archive decompression.
5. **Broaden provider and publication evidence.** Local vLLM text/image/tool integration is demonstrated; LM Studio is not live-tested. The small local model's incorrect answers remain recorded. Only CLEVR, PAIRS, and EuroSAT previews have public media approval; review additional records and media individually. GitHub Pages publishing remains an explicit deployment operation.

The interface closeout is complete: the rebuilt Ask-model panel sent and saved a real image conversation through local vLLM; the Analyze panel estimated and completed a real COCO detector and SigLIP2 image-embedding run, then refreshed their results into inspection. Catalogue, filtering, selection actions and contextual panels are tested at 390 px and 820 px. Metadata-only About panels and explicit result refresh are fixed.

A clean checkout without acquired data passed 159 Python checks and explicitly skipped 32 optional local-source checks. Those 32 checks passed in the prepared workspace. LM Studio remains untested.
