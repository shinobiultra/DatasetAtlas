# PAIRS preview publication review (2026-09-22)

This review covers only the pinned 100-image preview in `examples/approved-packs/pairs/`. It is a local publication-profile decision for a reproducible static build, not a remote deployment or a legal opinion.

The [author datasheet at commit `507075ac`](https://github.com/katiefraser/PAIRS/blob/507075ac84d244c4f98b965ba257b197d4944b04/Data%20Sheet.md) states in its Distribution section that the dataset is CC BY 4.0 and that the researchers own the Midjourney-generated images. Its Composition and Labeling sections state that the depicted people are synthetic and the demographic words describe generation prompts, not measured identities. It also warns that isolated images can reinforce stereotypes and advises against using the dataset to predict a depicted person's race or gender. The public catalogue must retain the source link, attribution, and this usage context.

The source archive is pinned by commit and SHA-256 (`0fae5bead2cd5f38dabf8e50e2ebdd0157a29eceb59d963abf6d29b2ce8ec9db`). The local adapter retains all 200 originals. The public candidate purposefully selects all 20 occupation scenarios and five status scenarios, each with all four prompt variants: 100 records, 25 complete groups. It excludes all potential-crime scenarios because their isolated display carries a higher stereotyping risk. Public records omit the local source-member path; they retain section, scenario, and prompt-word fields.

Every selected asset is an existing original 256×256 PNG. I verified all 100 file hashes against both `Asset.sha256` and the pack checksum manifest, decoded all 100 files as PNG, and checked the complete four-variant group count. I visually spot-checked 16 originals across airplane, scrubs, mopping, basketball, brick wall, bus, casual, and city scenes. No obviously disallowed imagery appeared in that spot check. This was **not** an exhaustive per-image visual inspection. The author-described composition, complete-group selection, exclusion of crime scenes, full file validation, and scoped visual review support the explicit 100-ID media allowlist in `registry/publication.json`.

The author-provided `prompt_race` and `prompt_gender` fields must always be described as prompt inputs, never inferred attributes of a person. The preview does not represent the diversity of real people or support identity classification. Public media remain off by default for every other dataset. A changed source archive, pack, asset ID, rights statement, or scenario selection requires a new review and profile update.
