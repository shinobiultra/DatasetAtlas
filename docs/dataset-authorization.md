# Access to supported sources

Each workspace uses its owner's source entitlements. The retained catalogue has
working native preparation paths; a fresh user may still need an account, accepted
publisher terms or a larger budget. Access to data does not authorize public
redistribution. The [coverage matrix](../reports/dataset_coverage.csv) and dataset
page distinguish the declared source population, local availability and rights.

The routes below are recorded source instructions, rather than a new availability
check. Review the publisher's current conditions in your own account.

| Supported source | Recorded access route | Scope |
| --- | --- | --- |
| Winoground | [facebook/winoground](https://huggingface.co/datasets/facebook/winoground) | Review and accept the repository's research-use and contact-sharing conditions. |
| ViSU-Text | [aimagelab/ViSU-Text](https://huggingface.co/datasets/aimagelab/ViSU-Text) | Follow its institutional access form. Authorization applies to this text release. |
| SORRY-Bench | [Author repository](https://github.com/SORRY-Bench/sorry-bench), [recorded HF release](https://huggingface.co/datasets/sorry-bench/sorry-bench-202503) | Review the conditions for the exact source population in the preparation plan. |
| ZeroBench | [jonathan-roberts1/zerobench](https://huggingface.co/datasets/jonathan-roberts1/zerobench) | Review the author-linked repository's access conditions. |
| ImageNet-1K | [ImageNet terms](https://www.image-net.org/download.php), [ILSVRC/imagenet-1k](https://huggingface.co/datasets/ILSVRC/imagenet-1k) | Obtain access for the needed release; related annotation sources retain their own terms. |
| Flickr30K | [Author instructions](https://shannon.cs.illinois.edu/DenotationGraph/), [recorded mirror](https://huggingface.co/datasets/nlphuji/flickr30k) | Follow the research/education access process. Image rights remain with their source owners. |
| CelebA | [Author page](https://mmlab.ie.cuhk.edu.hk/projects/CelebA.html) | Follow the terms for images and native annotations; separately requested identity labels are not supplied by an image mirror. |
| Ring-A-Bell | [Chia15/RingABell-Nudity](https://huggingface.co/datasets/Chia15/RingABell-Nudity), [author repository](https://github.com/chiayi-hsu/Ring-A-Bell) | Accept conditions for the declared text population. Its adversarial text stays local. |
| MultiTrust | [thu-ml/MultiTrust](https://huggingface.co/datasets/thu-ml/MultiTrust) | Accept the source conditions. Atlas preserves heterogeneous native task units and their image conditions; a unit is not automatically an image or a question. |
| SBBench / photographic BBQ-V release | [ucf-crcv/BBQ-V](https://huggingface.co/datasets/ucf-crcv/BBQ-V), [author instructions](https://github.com/UCF-CRCV/BBQ-Vision) | Accept terms for this pinned current release. Its membership and the historical paper population remain distinct. |
| MMA-Diffusion | [Author repository](https://github.com/cure-lab/MMA-Diffusion), [recorded text benchmark](https://huggingface.co/datasets/YijunYang280/MMA-Diffusion-NSFW-adv-prompts-benchmark) | Use the source population named by the active recipe. Other image releases and entitlements are separate. |
| PHANTOM | [it4lia/PHANTOM](https://huggingface.co/datasets/it4lia/PHANTOM) | Review its repository conditions. Conversation units and explicitly absent media remain part of the native representation. |

After obtaining access, use a local Hugging Face login or read token for that
account. Atlas's credential profile reads the locally available token when needed;
never put tokens in registry YAML, receipts or chat. Atlas does not accept
agreements, buy access or contact publishers for you.

For files you already obtained under appropriate terms, keep originals in one
location and register them with [your own datasets](adding-your-own-datasets.md).
The same rights constraints apply to selections, model context and exports.
Only the exact approved public packs enter [publication](publication.md).
