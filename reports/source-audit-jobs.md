# Direct-use source identity audit (2026-09-22)

This is official-source desk research for 20 assigned dataset groups, **not human review, publication approval, or complete-data coverage**. The machine-readable evidence is [`work/sources/source-audit-jobs.json`](../work/sources/source-audit-jobs.json). No registry entry, source archive, model, or corpus original was changed, and no dataset was downloaded for this audit. Public access and rights to annotations, images, captions, and code are recorded separately. In particular, a repository software license does not establish rights to third-party media.

| Group | Official identity, release and access | Rights and next source check |
| --- | --- | --- |
| ImageNet-1K | [ImageNet download](https://www.image-net.org/download.php): ILSVRC classification/localization 1,000-class subset, 1,281,167 train and 50,000 validation images; official page links selected subset via Kaggle and other access via registered terms. | Noncommercial research/education terms. Do not publicly redistribute images; pin challenge year and split. |
| VQAv2 | [Official v2 downloads](https://visualqa.org/download.html): balanced Real Images v2.0 with 443,757 train, 214,354 validation, 447,793 test questions; revised train/val files dated 2017-04-26. COCO images are a separate input. | [VQA annotations CC BY 4.0](https://visualqa.org/terms.html); COCO image rights remain separate. |
| TextVQA | [Official v0.5.1 dataset](https://textvqa.org/dataset/): v0.5 questions with updated/separate Rosetta OCR; Open Images photos separate; 34,602/5,000/5,734 train/val/test questions. | Project labels data CC BY 4.0. Check per-photo Open Images licenses and orientation before media display. |
| VizWiz-VQA | [Official 2020 VQA release](https://vizwiz.org/tasks-and-datasets/vqa/): 20,523 train, 4,319 val, 8,000 test pairs; distinct from deprecated 2019 release. The 2023 unsuitable→unanswerable label change matters. | Project page labels work CC BY 4.0. Photos are contributed by blind users and can show private details; visual examples need separate sensitive-media review. |
| GQA | [Stanford download](https://cs.stanford.edu/people/dorarad/gqa/download.html): scene graphs v1.1, questions v1.2, separate images, balanced/all questions. | No license established on checked page; source Visual Genome photos and annotation rights need direct review. |
| DataComp-1B | [Maintainer dataset card](https://huggingface.co/datasets/mlfoundations/datacomp_1b): about 1.39 billion URL-text metadata entries, with media fetched independently. | CC BY 4.0 is for metadata; linked third-party images retain their rights. Metadata-only bounded access is the plausible first step. |
| LAION-400M | [LAION original release](https://laion.ai/laion-400-open-dataset/): 400M English URL-caption pairs; public metadata Parquet, while a described 10 TB image WebDataset was internal-only for licensing reasons. | CC BY 4.0 is **metadata only**. URL targets are neither stable nor rights-cleared by that license. |
| ImageNet-Sketch | [Author repository](https://github.com/HaohanWang/ImageNet-Sketch): 50,000 sketches, 50 per 1,000 ImageNet classes; author links release mirrors. | MIT repository code license does not establish rights to Google-sourced sketch images. Archive/revision and per-image reuse remain open. |
| Caltech101 | [CaltechDATA v1.0](https://data.caltech.edu/records/mzrjq-6wc02): DOI `10.22002/D1.20086`, public 137.4 MB ZIP, MD5 `3138e1922a9193bfa496528edbbc45d0`. | Checked institutional record has no stated license. Open download alone does not approve media publication. |
| Stanford Cars | [Original author page](https://ai.stanford.edu/~jkrause/cars/car_dataset.html) returned 404; [author dissertation](https://ai.stanford.edu/~jkrause/papers/dissertation.pdf) establishes the dataset but not a current archive. | Original release, exact class variant, integrity and rights unresolved; find an author-linked/institutional archive before claiming access. |
| CelebA | [CUHK author page](https://mmlab.ie.cuhk.edu.hk/projects/CelebA.html): 202,599 face images, 10,177 identities, 40 attributes; image files publicly linked but identity labels require request. | Author agreement limits use to noncommercial research and restricts copying/redistribution. Keep faces and identity labels local. |
| COCOgender | DebiasLens cites Tang et al. 2021 for its image/caption training set; [Tang et al.'s author release](https://github.com/datamllab/Mitigating_Gender_Bias_In_Captioning_System) distinguishes COCO-GB V1/V2, while [DebiasLens supplement](https://openaccess.thecvf.com/content/CVPR2026/supplemental/An_Interpretable_Debiasing_of_CVPR_2026_supplemental.pdf) reports 12,454 examples. | **Exact COCOgender-to-COCO-GB file mapping and overlay license unresolved**. This registry candidate must not silently merge with `coco-gender`, a different paper's evaluation mention; COCO media rights are separate. |
| ImageNet-C | [Zenodo v1](https://zenodo.org/records/2235448), DOI `10.5281/zenodo.2235448`, hosts large corruption archives; [author repo](https://github.com/hendrycks/robustness) links them. | Repository license is not an image license; [ImageNet terms](https://www.image-net.org/download.php) still matter. Select corruption/severity and use an explicit bounded acquisition plan. |
| POPE | [Author repository](https://github.com/RUCAIBox/POPE): generated object-hallucination QA overlay with random/popular/adversarial negative sampling, often on COCO 2014 val. | Retain source image IDs and sampling settings; repository license does not confer COCO photo rights. |
| MME | [Original project](https://mme-benchmark.github.io/home_page.html) defines 14 perception/cognition tasks and manually designed answers. It links a GitHub dataset location, but that link could not be fetched here. | Exact data archive, revision, per-task image provenance and data license remain unverified. Website CC BY-SA footer is only site evidence. |
| SEED-Bench-2 | [Author dataset card](https://huggingface.co/datasets/AILab-CVC/SEED-Bench-2) lists about 24,000 questions across 27 dimensions; separate from Bench-1/2-Plus. | Card says CC BY-NC 4.0; [author media inventory](https://github.com/AILab-CVC/SEED-Bench/blob/main/DATASET.md) names numerous upstream datasets with their own terms. |
| MMBench | [OpenCompass author repo](https://github.com/open-compass/MMBench), with separate English/Chinese DEV/TEST releases and official [dataset card](https://huggingface.co/datasets/opencompass/MMBench). | Apache repo license alone does not establish rights to mixed-source images. Pin language, split, exact file revision and answer availability. |
| MMMU | [Official team data](https://huggingface.co/datasets/MMMU/MMMU) and [author repo](https://github.com/MMMU-Benchmark/MMMU): about 11,500 questions, six disciplines and thirty subjects, distinct from MMMU-Pro. | Team card says Apache-2.0; inspect reused textbook/educational imagery before public examples. Pin HF revision and subject subset. |
| RealToxicityPrompts | [AllenAI author repo](https://github.com/allenai/real-toxicity-prompts) describes 100,000 OpenWebText snippets with toxicity scores; [team dataset card](https://huggingface.co/datasets/allenai/real-toxicity-prompts) supplies files. | Repo Apache-2.0 is code evidence; hosted card's licensing prose appears templated for image metadata. Source web-text rights and harmful-content display need review. |
| AdvBench | [Author source CSV](https://github.com/llm-attacks/llm-attacks/tree/098262edf85f807224e70ecd87b9d83716bf6b73/data/advbench) has 520 harmful-behavior rows; local receipt pins commit `098262e` and SHA-256 `6cd1a5c63c07610d7eb67307772ee5606017ee950b5770ab288a2c487489d3e1`. | MIT repository license is visible, but data redistribution and harmful-content publication remain unreviewed. A prior 100-row local preview is separate from this source audit. |

Source identity is strongest for the officially hosted release families above; the concrete unresolved identities are Stanford Cars' original archive, COCOgender's exact overlay, and MME's data files. The other rights caveats are publication decisions, not reasons to call missing adapters or previews external blockers. Every row still needs exact revision/digest and a source-specific local receipt before claiming complete data coverage.
