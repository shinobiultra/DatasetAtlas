# EuroSAT RGB preview publication review (2026-09-22)

This review concerns only 100 original 64×64 JPEGs in the pinned [EuroSAT v2 RGB release](https://zenodo.org/records/7711810), selected ten per class from `work/packs/eurosat/pack.json`. It does not review or approve the 27,000-image release or the separate multispectral archive. Any approval here is for a local static build, not remote deployment or a legal opinion.

The [author README at commit `353fc2ff`](https://github.com/phelber/EuroSAT/blob/353fc2ff01447cbcf84c4496dd98e82f197515bd/README.md) explicitly licenses the EuroSAT dataset under MIT and identifies Sentinel-2 source imagery. The [European Commission legal notice](https://sentinels.copernicus.eu/documents/247904/690755/Sentinel_Data_Legal_Notice) permits reproduction, distribution, public communication, and modification of Copernicus Sentinel data, subject to a source notice for modified data. The RGB JPEGs are modified from the multispectral source, so a public preview must say **“Contains modified Copernicus Sentinel data 2015–2018.”** The range is an inference: the [original paper](https://arxiv.org/pdf/1709.00029) identifies Sentinel-2A as its source, [ESA dates Sentinel-2A's launch to June 2015](https://sentinels.copernicus.eu/-/second-copernicus-environmental-satellite-safely-in-orbit), and Zenodo identifies v2 as a 2018 release. The source does not disclose each JPEG's acquisition year; [author issue #8](https://github.com/phelber/EuroSAT/issues/8) records that missing date/georeference mapping. The range is a dataset-level source notice, not a per-image capture-date claim.

The RGB ZIP is 94,658,721 bytes, with Zenodo MD5 `f46e308c4d50d4bf32fedad2d3d62f3b` and local SHA-256 `b4f5b234ecb7d7ff9c6cddb046543b4717c53fd6e9815be6c0e80cc614f51b90`. I validated the preview's 100 asset SHA-256 values against both `Asset.sha256` and the pack checksum manifest. All 100 files decoded as JPEG at 64×64 pixels. The pack contains ten examples from each of the ten original class folders. I visually inspected one original per class; each showed coarse satellite land cover, and no person or identifiable personal content was apparent. This was a spot check, not exhaustive visual inspection.

The approved public pack omits the local `source.path` field and retains only the label and source filename. The registry now approves records, annotations, and images for this scoped preview; `registry/publication.json` allowlists exactly its 100 asset IDs. The built public catalogue carries the EuroSAT author citation, MIT dataset terms, and Copernicus modified-data notice and link. The full pinned MIT copyright and permission notice (SHA-256 `73b8c5d100ff46a84845702b9e78d76ddb1effaacdb386b91dc07061c6123362`) is bundled at `apps/web/public/licenses/eurosat-MIT.txt` and alongside the approved pack. This is a local build decision; no remote deployment has occurred. A changed archive, preview selection, or source notice requires a new scoped review.
